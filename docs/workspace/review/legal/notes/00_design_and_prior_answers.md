# 설계 요약 (조사 대상)
- 연구 기관 에이전트가 연구에 빠진 데이터를 LLM으로 추론(어떤 항목이 부족한지)하고 요청.
- 사람 한 명의 종합 건강 기록(웨어러블·병원 진료기록·설문, 시간축)을 그 사람의 개인 에이전트가 회차·용도별 동의 범위 안에서 엮어 기관 공개키로 봉인(암호화)해 기여.
- 연구별 가명 ID, 최소 항목, 위험 조합(준식별자 조합) 차단.
- 철회 3종: (1) 이번 회차 거절, (2) 향후 공급 중단, (3) 데이터 접근 동의 철회.
- 대가는 XRPL로 참여자에게 정산: Escrow(조건부 지급), MPT(Multi-Purpose Token) 라이선스 발행·회수(clawback), 윤리 승인(IRB) 상태를 XRPL Credential로 표시.
- 데모는 합성 데이터 + XRPL Testnet만. 실제 건강정보·실제 자금 없음.
- 대상 국가: 한국(본사/참여자), 몽골(UniQdata Core 서버·참여자·병원 파트너), 미국(해커톤 NYC, 잠재 연구기관).
- 금지 표현: "데이터 판매", "리워드", "재식별 불가", "질병 예측". 대신 "연구 기여", "참여 대가/정산", "재식별 위험 감소", "연구용 결측 추론" 사용.

# daniel이 최근 받은 답변(이전 AI 리서치 대화)에서 이미 나온 법적 포인트 — 검증·보강 대상
1. 한국 개인정보 보호법 제17조: 동의 기반 제3자 제공 시 제공받는 자·목적·항목·보유기간·거부권 고지, 변경 시 재고지·재동의 → "같은 기관이니 추가 항목 자동 제공"은 기본값 불가. 처음 동의 화면에서 범위를 명시했다면 그 범위 내 반복 자동 실행 설계 가능.
2. 제23조 민감정보(건강): 별도 동의 또는 법령 근거 필요. 내부 '생활데이터' 등급 명명으로 생략 불가.
3. 가명정보(과학적 연구) 경로(제28조의2)는 동의 외 근거로 존재 → 모든 연구 활용에 동의 필수라고 일반화하지 말 것. MVP는 동의+위임 중심.
4. 국외 이전: 한국법상 해외에서 조회되는 경우도 이전에 포함 → 서버 국내 위치만으로 검토 종료 아님.
5. 일본 PPC FAQ: 예측 가능한 제3자 제공은 사전 동의 가능, 매번 재동의 불필요(참고용 비교).
6. 미국 Common Rule broad consent(45 CFR 46.116(d)): 연구 유형·정보 종류·기관 유형·기간을 설명하는 범위 내 묶음 동의 가능.
7. 미국 OHRP 철회 지침: 철회 전 수집 자료는 승인된 프로토콜 범위에서 보관·분석 가능 → "철회=기존 데이터 전부 삭제"로 설명하면 안 됨. 이미 전달된 평문 사본은 키 폐기로 회수 불가.
8. NIH: 기존 승인 프로토콜 범위 활동 vs 새 목적 후속연구 구분.
9. IRB 승인서 해시를 체인에 남기는 것 ≠ 승인 진위 확인. 에이전트는 IRB 승인/면제를 스스로 발행하지 않음. LLM이 "승인" 단어를 찾았다고 유효 승인으로 확정 금지.
10. XRPL: 원장 공개 → 건강 원문·진단명·이름·동의서 전문·키 온체인 금지, 지급 주소 연결이 참여 사실을 드러낼 가능성. Escrow는 CancelAfter 이후 취소, 생성된 에스크로 조건은 철회 기록으로 바뀌지 않음. Credentials는 발급자 진술일 뿐 접근 집행은 별도 구현 필요. 검증된 원장(validated ledger)에서 결과 확인.
11. 결제 사실이 데이터 이용 동의를 대신하지 않음. AP2 명세: 동의 화면은 비에이전트·검증은 결정적 코드 → LLM이 동의 범위를 확장 추정 금지.
12. 고령자: 가족에게 동의 권한 기본 부여 금지.
