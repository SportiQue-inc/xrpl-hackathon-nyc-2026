# Workspace: research, legal basis and evidence (2026-10-24 to 10-25)

Research, legal and design material the team wrote outside the code during the
hackathon, copied from the project's shared folder so it has history. Each
folder was committed in the order it was written, one commit per topic.

| Folder | What is in it |
|---|---|
| `research/` | Starting context (design, plan), agent-payment landscape report and notes, market-potential memo |
| `review/legal/` | Legal basis for Korea, Mongolia and the US, verified articles, withdrawal and penalty reviews |
| `review/research_notes/`, `review/reports/`, `review/market-deep-dive.md` | Healthcare data market deep dive |
| `review/security/` | Security review, binding and key release, UniQdata batch-consent review |
| `review/*.md` | Before/after and bottleneck scenes, passkey contract, legal Q&A, consent-to-law mapping |
| `review/workflow/`, `review/reshoot/`, `review/try-redesign/`, `review/slides/`, `review/img/` | Workflow page, re-shot evidence, /try redesign, slide images, flow diagram |
| `agentrail-ui/` | Screen captures, before/after and bottleneck scenes, consent flow, Figma exports |
| `vault-market/`, `vault-shots/`, `tutorial/` | Data Vault Market platform notes, screenshots and judge-guide captures |
| `demo/`, `network-replay*.html` | Act 1 run records and node-network replays |
| `submission/` | Submission form (v1 and AP4M v2) |
