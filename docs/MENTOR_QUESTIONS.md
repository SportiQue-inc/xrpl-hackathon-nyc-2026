# Questions for mentors

1. Track fit: does consent-bound data delivery plus automatic Testnet settlement fit
   Agentic Finance, or is Protocol Innovation / Why Not? a better match?
2. Stack: native XRPL Testnet (Payments, Memos) vs XRPL EVM Testnet with a contract -
   which do judges and sponsors (e.g. QuickNode) expect for this kind of flow?
3. Escrow: is a native XRPL Escrow (or a conditional payment) worth showing for
   "pay only after a verified delivery receipt", or is idempotent Payment enough?
4. Reuse disclosure: is a REUSE_LOG plus separate import commits sufficient, and
   does the submitted repo need to be public?
5. Commitments: recommended pattern for salted commitments of agreement versions on
   XRPL without leaking timing or content.
