What changes

More sharing for people. Better-fit data for researchers.

For the person’s agent

  • Shares routine data on its own, so people share more often
  • More contributions means more income, paid per round in RLUSD
  • Sovereignty kept: sensitive data and new uses always come back to them
  • Withdraw any time; payments already received stay theirs

For the researcher’s agent

  • Reads the protocol and finds exactly which data is missing
  • Compares offers agent to agent, not person to person
  • Checks a sample before paying; unfit data is dropped first
  • Gets cleaner, consented data, faster and safer
What does that change? For people, their agent shares routine data on its own, so they share more often and earn more, while sensitive data and new uses still come back to them. For researchers, their agent finds exactly what is missing, compares offers agent to agent, checks samples before paying, and ends up with better-fit, higher-quality data.
