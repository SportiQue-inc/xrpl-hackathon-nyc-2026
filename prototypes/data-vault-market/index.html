Data Vault Market

Everyone keeps their own data in their own vault and marks what they would sell. An agent sorts the vault into packages, matches buyer requests across many vaults, and sells only after each owner taps OK. Delivery is sealed to the buyer, and the escrow pays the owner at the moment it releases the key.

    All files, owners and the buyer are synthetic. Pseudonymization, provenance signatures, sealing (ECDH P-256 + AES-GCM) and the escrow condition use real Web Crypto in your browser; the ledger is an in-page simulation. The sorting and matching agent is rule-based here so the demo is deterministic; an LLM can propose the same packages, and code still checks the result before anything is offered.
