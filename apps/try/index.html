AP4M · Mastercard agent payments

The agent pays per export in RLUSD, and anyone can check it on chain

Next to the XRPL escrow and key reveal, the participant's agent can pay on the AP4M rail: it opens a Channel with requestChannel(), pays each export call with a signed Voucher inside its cap, and refuses anything over the cap. Each redeemed Voucher is a transaction on XRPL EVM Testnet.
